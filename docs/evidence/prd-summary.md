# PRD Summary

## Problem

개인의 MBTI와 공동 소비 행동은 항상 같지 않지만, 기존 모임통장과 가계부는 거래 기록의 행동적 의미를 해석해주지 않는다.

## Solution

UFC는 구성원 MBTI와 모임통장 거래 패턴을 함께 분석해 통장만의 소비 MBTI, 비교 리포트, 소비 패턴 그래프를 제공한다.

## MVP Includes

- 2~4명의 모임 생성
- 구성원 MBTI 입력
- 거래 내역 업로드 또는 Mock 데이터 선택
- 소비 행동 지표 계산
- 모임통장 소비 MBTI 부여
- 구성원 MBTI와 비교
- LLM 요약 리포트
- 소비 패턴 그래프
- 결과 공유 카드

## MVP Excludes

- 실제 은행 계좌 연결
- 송금과 자동이체
- 신용점수 분석
- 금융상품 추천
- 실제 성격 진단
- 대규모 조직 회비 관리
- 투자 및 자산관리 컨설팅

## Product Definition

UFC는 부부·연인과 소규모 친구 모임의 개인 MBTI와 모임통장 거래 패턴을 함께 분석해, 공동 소비의 MBTI와 그 형성 근거를 AI 리포트와 관계형 그래프로 보여주는 서비스다.
