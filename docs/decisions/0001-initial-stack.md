# 0001. Initial Stack

## Status

Accepted

## Decision

UFC MVP uses FastAPI, SQLAlchemy, Alembic, Pydantic, PostgreSQL, React, TypeScript, and Vite.

## Rationale

- FastAPI provides a compact Python API layer and first-class Pydantic integration.
- SQLAlchemy fills the ORM role similar to Django ORM.
- Alembic manages schema changes similar to Django migrations.
- PostgreSQL stores relational user, group, transaction, analysis, and report data.
- React and Vite provide a lightweight frontend setup for result exploration and graph views.
